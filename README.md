# Clean Web Reader (极简网页版 PDF & EPUB 阅读器)

> 一个遵循**“克制设计、隐形交互、专注内容”**哲学的纯前端本地化网页阅读器，全面支持 **PDF 矢量排版** 与 **EPUB 流式重排电子书**，内置划词高亮、批注笔记、大纲导航、断点续读与超长文档虚拟内存回收。

🌐 **在线体验**：[https://jiafeng123.github.io/clean-pdf-reader/](https://jiafeng123.github.io/clean-pdf-reader/)

---

## ✨ 核心特性

1. **双格式无缝支持（PDF + EPUB）**
   - **PDF 模式**：Retina 超清矢量渲染、连续滚动、单页幻灯、双页展卷、大部头长文档显存回收。
   - **EPUB 模式**：自适应流式排版、动态字号缩放、章节进度精确追踪、目录大纲树原生解析、阅读位置 CFI 断点记忆。
   - **拖拽自适应**：拖入 `.pdf` 或 `.epub` 即可自动秒开对应解析引擎。

2. **界面干净·极简专注**
   - **顶置精简控制岛**：50px 高度高透磨砂毛玻璃顶栏，绝不遮挡文档正文，两端智能对齐防越界 Tooltip。
   - **真实环境光纸张感**：微米级柔和多层阴影与视口留白，还原书本阅读体验。
   - **4 种精选阅读主题**（按 `D` 键快速切换）：
     - `Studio`（经典纯净工作室白）
     - `Warm`（温暖宣纸米黄·护眼防疲劳）
     - `Night`（黑曜石暗夜·智能软化反色）
     - `E-Ink`（墨水屏黑白灰·沉浸专注）

3. **智能划词与笔记系统**
   - **悬浮划词工具条**：页面划选任意文字立即浮现微交互菜单。
   - **4 色荧光笔高亮**：晨曦黄、薄荷绿、晴空蓝、罗兰紫。
   - **随时添加批注思考**：将金句引用与个人读书心得结合，自动按页码/章节归档。
   - **一键导出 Markdown**：点击“导出 MD”生成结构化笔记文件，无缝衔接 Obsidian / Notion / Logseq。
   - **纯本地持久化**：笔记基于 `localStorage` 本地保存，文件永不外传。

4. **100% 离线·私密安全与 PWA**
   - PDF.js 与 ePub.js / JSZip 核心库已完整本地化打包在 `lib/` 目录下。
   - 纯浏览器客户端渲染，无需网络，离线即用，完全保护隐私。
   - 支持 PWA 离线运行，可在浏览器中直接点击「安装为桌面应用」。

## ⌨️ 快捷键指南

| 快捷键 | 功能说明 |
| :--- | :--- |
| `J` / `↓` / `PageDown` / `Space` | 下一页 / 向下翻页 |
| `K` / `↑` / `PageUp` | 上一页 / 向上翻页 |
| `+` / `=` | 放大页面视图（EPUB 增大字号） |
| `-` | 缩小页面视图（EPUB 缩小字号） |
| `0` | 重置缩放/字号为 100% |
| `W` | 自动适应页面宽度 (PDF) |
| `P` | 自动适应整页视图 (PDF) |
| `[` | 展开 / 折叠侧边栏（缩略图、目录、笔记） |
| `D` | 循环切换护眼阅读主题（工作室 / 暖纸 / 暗夜 / 墨水屏） |
| `F` | 进入 / 退出全屏禅模式 |
| `R` | 顺时针旋转 90 度 (PDF) |
| `Ctrl + F` / `Cmd + F` | 开启文档内即时搜索 |
| `ESC` | 退出搜索 / 全屏 |

## 🚀 启动与使用

### 方式 1：在线访问
直接访问 GitHub Pages 部署链接：[https://jiafeng123.github.io/clean-pdf-reader/](https://jiafeng123.github.io/clean-pdf-reader/)

进入 `clean-pdf-reader` 目录，直接双击运行 **`start.bat`** 或在浏览器中直接双击打开 **`index.html`** 即可。
