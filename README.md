# Clean Web PDF Reader (极简网页版 PDF 阅读器)

> 一个遵循**“克制设计、隐形交互、专注内容”**哲学的纯前端本地化网页 PDF 阅读器，内置划词高亮、批注笔记、大纲导航、断点续读与超长文档虚拟内存回收。

🌐 **在线体验**：[https://jiafeng123.github.io/clean-pdf-reader/](https://jiafeng123.github.io/clean-pdf-reader/)

---

## ✨ 核心特性

1. **界面干净·极简专注**
   - **顶置精简控制岛**：50px 高度高透磨砂毛玻璃顶栏，绝不遮挡文档正文，两端智能对齐防越界 Tooltip。
   - **真实环境光纸张感**：微米级柔和多层阴影与视口留白，还原书本阅读体验。
   - **4 种精选阅读主题**（按 `D` 键快速切换）：
     - `Studio`（经典纯净工作室白）
     - `Warm`（温暖宣纸米黄·护眼防疲劳）
     - `Night`（黑曜石暗夜·智能软化反色）
     - `E-Ink`（墨水屏黑白灰·沉浸专注）

2. **高保真排版与精准导航**
   - **Retina / High-DPI 超清矢量渲染**：自动匹配物理像素比，矢量文字绝不发虚。
   - **多版式自由切换**：连续滚动 (Continuous)、单页幻灯 (Single)、双页展卷 (Spread)。
   - **双向目录大纲联动**：右侧滚动时左侧章节目录自动高亮跟随，点击大纲瞬间平滑跳转对应页。
   - **断点记忆续读**：基于 `localStorage` 自动记忆上次阅读进度，下次打开即刻平滑续读。
   - **大部头虚拟内存回收**：百页长文档自动回收屏幕外渲染显存，保持超低内存占用与丝滑 60fps。

3. **智能划词与笔记系统**
   - **悬浮划词工具条**：页面划选任意文字立即浮现微交互菜单。
   - **4 色荧光笔高亮**：晨曦黄、薄荷绿、晴空蓝、罗兰紫。
   - **随时添加批注思考**：将金句引用与个人读书心得结合，自动按页码归档。
   - **一键导出 Markdown**：点击“导出 MD”生成结构化笔记文件，无缝衔接 Obsidian / Notion / Logseq。
   - **纯本地持久化**：笔记基于 `localStorage` 本地保存，文件永不外传。

4. **100% 离线·私密安全与 PWA**
   - PDF.js 核心库与 Worker 已完整本地化打包在 `lib/` 目录下。
   - 纯浏览器客户端渲染，无需网络，离线即用，完全保护隐私。
   - 支持 PWA 离线运行，可在浏览器中直接点击「安装为桌面应用」。

## ⌨️ 快捷键指南

| 快捷键 | 功能说明 |
| :--- | :--- |
| `J` / `↓` / `PageDown` | 下一页 / 向下平滑滚动 |
| `K` / `↑` / `PageUp` | 上一页 / 向上平滑滚动 |
| `+` / `=` | 放大页面视图 |
| `-` | 缩小页面视图 |
| `0` | 重置缩放为 100% |
| `W` | 自动适应页面宽度 (Fit Width) |
| `P` | 自动适应整页视图 (Fit Page) |
| `[` | 展开 / 折叠侧边栏（缩略图、目录、笔记） |
| `D` | 循环切换护眼阅读主题（工作室 / 暖纸 / 暗夜 / 墨水屏） |
| `F` | 进入 / 退出全屏禅模式 |
| `R` | 顺时针旋转 90 度 |
| `Ctrl + F` / `Cmd + F` | 开启文档内即时搜索 |
| `ESC` | 退出搜索 / 全屏 |

## 🚀 启动与使用

### 方式 1：在线访问
直接访问 GitHub Pages 部署链接：[https://jiafeng123.github.io/clean-pdf-reader/](https://jiafeng123.github.io/clean-pdf-reader/)

### 方式 2：本地直接双击打开
进入 `clean-pdf-reader` 目录，直接双击运行 **`start.bat`** 或在浏览器中直接双击打开 **`index.html`** 即可。
